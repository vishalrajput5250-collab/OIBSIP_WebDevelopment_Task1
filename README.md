Snake Game

Objective

The objective of this project is to develop a simple and interactive Snake Game using web technologies. The game allows the player to control the snake, collect food, increase the score, and continue playing until the game is over.

Project Features

- Interactive Snake Game
- Keyboard controls for snake movement
- Random food generation
- Score tracking
- Game-over functionality
- Simple and user-friendly interface
- Responsive game experience

Technologies Used

- HTML5
- CSS3
- JavaScript

Steps Performed

1. Created the basic structure of the Snake Game using HTML.
2. Designed the game interface using CSS.
3. Implemented snake movement using JavaScript.
4. Added food generation and collision detection.
5. Implemented score tracking.
6. Added game-over functionality.
7. Tested the game to ensure the main features work correctly.

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Use the keyboard arrow keys to control the snake.
5. Collect the food to increase your score.

Outcome

The Snake Game was successfully developed as part of the Web Development internship task. The project demonstrates the use of HTML, CSS, and JavaScript to create an interactive browser-based game.
